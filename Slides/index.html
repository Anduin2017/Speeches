第三章：从高中生都能懂的 K-Means 开始

高中生也能懂的 K-Means

  • 人类视觉天生擅长寻找“相似”和“聚集”
  • 直觉分类：散客 vs 高端商务客
  • 计算机没有视觉，依靠计算距离分类
  • 概要：画一个 X-Y 坐标系，散落两坨点。大家凭直觉就能看出它们分属两类。人类的视觉天生擅长寻找“相似”和“聚集”。

想象一下，我们现在有一张巨大的白纸，画上 X 轴和 Y 轴。假设 X 轴代表一个旅客过去一年购买机票的“次数”，Y 轴代表他每次购买机票的“平均价格”。

现在，把我们虚拟的航空公司的一万个客户数据撒到这个坐标系里，每一个客户就是一个点。（这里的数据都是假的）

作为人类，你哪怕只是远远地瞥一眼这张图，你的直觉立刻就会告诉你：这里大概有“两坨”人。左下角有一大聚落（买得少且便宜，可能是偶尔旅游的散客），右上角有一小聚落（买得多且贵，这是我们的高端商务常旅客）。或者说，我们可以快速从这个表里得到一个粗略的结论：经常乘坐飞机的人，往往消费能力也更强。

看，人类的视觉天生就十分擅长寻找“相似”和“聚集”。你不需要任何复杂的计算，一眼就能把客户分好类。

早期人工智能：K-Means 算法

  • 计算机通过“算距离”理解相似性
  • 核心公式：欧氏距离（勾股定理）
  • 不断迭代寻找最佳分类聚落

但是，计算机没有眼睛，它看不到“两坨”点。那计算机要怎么把这些客户分类呢？这时候，一种古老、简单，但又可以说是早期“人工智能”代表的算法登场了——它叫 K-Means（K-均值聚类）。

计算机不靠“看”，它靠“算”。它计算什么？计算点和点之间的直线距离。

大家还记得初中学的勾股定理吗？在二维平面上，两个点 \((x_1, y_1)\) 和 \((x_2, y_2)\) 之间的直线距离（在数学上叫欧氏距离），公式是这样的:

\[d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\]

计算机的做法简单粗暴：它先在纸上瞎蒙两个中心点，然后把所有的客户点都拿来算一遍距离。谁离中心点 A 更近，谁就归属 A 类；谁离 B 近，就归属 B 类。分完之后，它再根据分好的群体重新找更准确的中心点，再算一遍距离。循环几次，直到一切稳定下来。

结果你会发现，计算机通过这种死磕“算距离”的笨办法，最终得出的分类结果，和我们人类一眼看出来的“两坨”一模一样。

距离近的圈在一起，这就是计算机理解“相似性”的唯一方式。

跨越维度的鸿沟

  • 从两维到三维：年龄
  • 增加维度：餐食、航线、偏好…
  • 千维空间：人类大脑无法想象
  • 计算机：维度不是问题！

二维很好理解。现在，我们给这个坐标系加上一个 Z 轴，比如代表这个旅客的“年龄”。 \((x, y, z)\)，这是一个三维立体空间，我们的点悬浮在了半空中。没关系，我们的大脑依然能想象出来，计算机也只需要在公式里再加一项即可。

接下来，我们需要进行一次逻辑上的推演。

如果我们再加一个维度，比如“偏好餐食（素食/肉食）”，再加一个“是否带小孩”，再加一个“常飞航线”，再加一千个、一万个描述这个旅客的特征……

到了四维、五维甚至一千维，我们人类的大脑就难以处理了，我们根本无法想象一个一千维的空间长什么样。但是，计算机完全不care！

计算机眼中的“相似”

  • 高维距离与低维数学本质相同
  • 特征完美统一转化为响量
  • 两向量差的模 = 相似度

在计算机眼里，算 2 个数字的距离，和算 1000 个数字的距离，在数学本质上没有任何区别。它的距离公式无非就是变得更长了而已：

\[d = \sqrt{\sum_{i=1}^{n} (x_i - y_i)^2}\]

这个距离是两个点的欧氏距离。为了简化上面的公式，我们把它写成向量的形式：

\[d = \| \mathbf{x} - \mathbf{y} \|\]

可以看出，两个向量的距离，就是它们的差的模（长度）。这就是计算机理解“相似性”的方式。

### 4.1 给世界贴标签：博客文章的数字化实验

为了让大家更直观地感受到向量的魔力，我们从最简单的手工打标签开始。假设在我们航空公司的内部知识库里，我刚刚写了三篇短小精悍的博客。

现在，我来给它们手工打上标签（Tag）：

* **第一篇博客：** 讲的是 “A320 的起飞”。我给它打的标签是：**空客、起飞**。
* **第二篇博客：** 讲的是 “737 的降落”。我给它打的标签是：**波音、降落**。
* **第三篇博客：** 讲的是 “飞机的起降原理”。我给它打的标签是：**起飞、降落**。

接下来，接下来我们看看实际效果。我们要把这三篇充满文字的博客，变成计算机能看懂的“向量”。

假设我们的系统目前很简陋，一共只有 4 个维度的标签，我们按照顺序排列它们：维度1是“空客”，维度2是“起飞”，维度3是“降落”，维度4是“波音”。如果博客包含了这个标签，我们就记为 1，没有就记为 0。

按照这个规则，我们的三篇博客瞬间就变成了空间里的三个向量：

| 博客文章 | 维度 1：空客 | 维度 2：起飞 | 维度 3：降落 | 维度 4：波音 | 最终生成的特征向量 |
| --- | --- | --- | --- | --- | --- |
| **第一篇 (A320 的起飞)** | 1 | 1 | 0 | 0 | `[1, 1, 0, 0]` |
| **第二篇 (737 的降落)** | 0 | 0 | 1 | 1 | `[0, 0, 1, 1]` |
| **第三篇 (飞机的起降原理)** | 0 | 1 | 1 | 0 | `[0, 1, 1, 0]` |

看，文字消失了，取而代之的是纯粹的数字。计算机通过算距离会发现，第三篇博客和第一篇、第二篇都有交集（距离比较近），而第一篇和第二篇可谓是风马牛不相及（距离最远）。

我们可以实际计算一下：第一篇（A320的起飞）和第二篇（737的降落）之间的直线距离（欧氏距离）是：

$$d = \sqrt{(1-0)^2 + (1-0)^2 + (0-1)^2 + (0-1)^2} = \sqrt{4} = 2$$

而第一篇（A320的起飞）和第三篇（飞机的起降原理）之间的欧氏距离是：

$$d = \sqrt{(1-0)^2 + (1-1)^2 + (0-1)^2 + (0-0)^2} = \sqrt{2} \approx 1.41$$

因为 1.41 小于 2，所以计算机得出结论：第一篇和第三篇更相似。这和我们人类的直觉完全一致。
:::

### 4.2 欧氏距离的致命漏洞：第四篇文章的乱入

看起来很完美，对吧？但是，假设此时，我们的知识库里混进了一篇完全不搭嘎的第四篇文章：**“炒方便面的做法”**。

很显然，这篇文章既没有空客，也没有波音，既不起飞，也不降落。所以，按照我们的规则，它的特征向量全是 0：

* **第四篇 (炒方便面)：** `[0, 0, 0, 0]` （如果它一定有标签，可能是：餐饮，就算是 [0, 0, 0, 0, 1]）

现在，我们让计算机算一下，第一篇（A320的起飞）和这篇（炒方便面）之间的欧氏距离：

$$d = \sqrt{(1-0)^2 + (1-0)^2 + (0-0)^2 + (0-0)^2} = \sqrt{2} \approx 1.41$$

这里存在一个明显的逻辑漏洞。

第一篇（A320起飞）和第三篇（起降原理）的距离是 **1.41**。
第一篇（A320起飞）和第四篇（炒方便面）的距离竟然也是 **1.41**！

这显然是荒谬的。问题究竟出在哪里？

问题在于：**欧氏距离无法真正反映“相关性”。** 在欧氏距离的计算公式里，你因为“拥有一个不同的特征”所产生的距离，和你“缺失一个特征”所产生的距离，在数学上被等同对待了。这在处理高维稀疏特征时，是一场灾难。

### 4.3 换个角度看世界：点乘与夹角余弦

为了解决这个致命漏洞，我们要从初中几何稍微往前走半步，回忆一下高中数学里的另一个核心概念：**向量的点乘（内积）**。

什么是点乘？最直白的理解，点乘就是把两个向量在相同维度上的数字两两相乘，然后再全加起来。

我们用点乘来重新审视一下刚才的三篇文章：

* **A320起飞** `[1, 1, 0, 0]` 与 **起降原理** `[0, 1, 1, 0]` 的点乘：
$1\times0 + 1\times1 + 0\times1 + 0\times0 = 1$
（结果大于 0，说明它们在某个维度上有共鸣，产生了交集！）
* **A320起飞** `[1, 1, 0, 0]` 与 **炒方便面** `[0, 0, 0, 0]` 的点乘：
$1\times0 + 1\times0 + 0\times0 + 0\times0 = 0$
（结果是 0，说明它们无论怎么乘，都激不起任何水花，毫不相干！）

看！仅仅换了一种简单的数学运算，炒方便面就被系统完美地踢出了局。

在高中数学里，两个向量 $\mathbf{x}$ 和 $\mathbf{y}$ 的点乘，在几何上有一个优美的公式：

$$\mathbf{x} \cdot \mathbf{y} = \|\mathbf{x}\| \|\mathbf{y}\| \cos(\theta)$$

这里的 $\|\mathbf{x}\|$ 和 $\|\mathbf{y}\|$ 是两个向量的模（也就是长度），而 $\theta$ 是它们在多维空间中的夹角。

如果我们只想知道这两个向量的“方向”是不是一致的，我们其实只需要看那个夹角 $\theta$。把长度除过去，我们就得到了现代人工智能评估相似度最核心的公式——**余弦相似度 (Cosine Similarity)**：

$$\cos(\theta) = \frac{\mathbf{x} \cdot \mathbf{y}}{\|\mathbf{x}\| \|\mathbf{y}\|}$$

* 如果两篇文章方向完全一致，夹角 $\theta = 0^\circ$，$\cos(0^\circ) = 1$。这就是**绝对契合**。
* 如果两篇文章风马牛不相及（方向完全垂直），夹角 $\theta = 90^\circ$，$\cos(90^\circ) = 0$。

只要我们抛弃绝对的直线距离，转而去计算**夹角余弦**，“炒方便面”的闹剧就永远不会发生了。

### 4.4 终极技术：L2 归一化 (L2 Normalization)

讲到这里，有高中数学常识的各位可能会问出一个十分本质的问题：

**欧氏距离，夹角余弦，点乘。这三个东西，到底是什么关系？难道我们在写 AI 代码的时候，要根据不同的场景在它们之间切来切去吗？**

这不符合计算机科学中“大道至简”的美学。于是，AI 工程师们施展了一个巧妙的数学运算——**L2 归一化 (L2 Normalization)**。

既然各个向量的“长度”不一会干扰我们的计算，那我们在把向量存入数据库之前，做一个暴力的操作：**强行把所有向量的长度变成 1。**

在数学上，就是用向量里的每一个数字，除以它自己的模长。在几何上，这意味着把多维空间里所有长短不一的向量，全部拉伸或压缩，统一投射到一个**“单位超球面”**的表面上。

现在，接下来我们看看实际效果。

假设所有的向量都从原点出发，且它们的模长全都被强制变成了 1，即 $\|\mathbf{x}\| = 1$ 且 $\|\mathbf{y}\| = 1$。那么我们来看看最初的那三个概念会发生什么奇妙的化学反应：

**第一，关于点乘。**
根据刚才的公式：$\mathbf{x} \cdot \mathbf{y} = \|\mathbf{x}\| \|\mathbf{y}\| \cos(\theta)$
代入长度为 1：$\mathbf{x} \cdot \mathbf{y} = 1 \times 1 \times \cos(\theta) = \cos(\theta)$
结论：**在单位超球面上，两个向量的点乘，直接等于它们的夹角余弦！**

**第二，关于欧氏距离。**
我们来算一下这两个终点之间的直线距离的平方 $d^2 = \|\mathbf{x} - \mathbf{y}\|^2$。
大家还记得初中的完全平方公式吗？在向量世界里，它叫余弦定理展开：

$$\\|\mathbf{x} - \mathbf{y}\|^2 = \|\mathbf{x}\|^2 + \|\mathbf{y}\|^2 - 2(\mathbf{x} \cdot \mathbf{y})$$

把长度为 1 代进去：

$$d^2 = 1^2 + 1^2 - 2\cos(\theta) = 2 - 2\cos(\theta)$$

得出最终的完美公式：

$$d = \sqrt{2 - 2\cos(\theta)}$$

**它把直线的距离（$d$）和旋转的角度（$\cos(\theta)$），十分完美地绑定在了一起。**

当两篇文章越来越相似时，夹角越来越小，$\cos(\theta)$ 越来越接近 1。此时，公式里的 $2 - 2 \times 1 = 0$，欧氏距离 $d$ 也就无限趋近于 0。

殊途同归！在完成了 L2 归一化之后，无论你是算点乘、算余弦相似度、还是算欧氏距离，在数学本质上已经是**完全等价**的了！

假设我们的系统目前很简陋，一共只有 4 个维度的标签，我们按照顺序排列它们：维度1是“空客”，维度2是“起飞”，维度3是“降落”，维度4是“波音”。如果博客包含了这个标签，我们就记为 1，没有就记为 0。

按照这个规则，我们的三篇博客瞬间就变成了空间里的三个向量：

| 博客文章 | 维度 1：空客 | 维度 2：起飞 | 维度 3：降落 | 维度 4：波音 | 最终生成的特征向量 |
| --- | --- | --- | --- | --- | --- |
| **第一篇 (A320 的起飞)** | 1 | 1 | 0 | 0 | `[1, 1, 0, 0]` |
| **第二篇 (737 的降落)** | 0 | 0 | 1 | 1 | `[0, 0, 1, 1]` |
| **第三篇 (飞机的起降原理)** | 0 | 1 | 1 | 0 | `[0, 1, 1, 0]` |

看，文字消失了，取而代之的是纯粹的数字。计算机通过算距离会发现，第三篇博客和第一篇、第二篇都有交集（距离比较近），而第一篇和第二篇可谓是风马牛不相及（距离最远）。

我们可以实际计算一下：第一篇（A320的起飞）和第二篇（737的降落）之间的直线距离（欧氏距离）是：

$$d = \sqrt{(1-0)^2 + (1-0)^2 + (0-1)^2 + (0-1)^2} = \sqrt{4} = 2$$

而第一篇（A320的起飞）和第三篇（飞机的起降原理）之间的欧氏距离是：

$$d = \sqrt{(1-0)^2 + (1-1)^2 + (0-1)^2 + (0-0)^2} = \sqrt{2} \approx 1.41$$

因为 1.41 小于 2，所以计算机得出结论：第一篇和第三篇更相似。这和我们人类的直觉完全一致。

### 4.2 欧氏距离的致命漏洞：第四篇文章的乱入

看起来很完美，对吧？但是，假设此时，我们的知识库里混进了一篇完全不搭嘎的第四篇文章：**“炒方便面的做法”**。

很显然，这篇文章既没有空客，也没有波音，既不起飞，也不降落。所以，按照我们的规则，它的特征向量全是 0：

* **第四篇 (炒方便面)：** `[0, 0, 0, 0]` （如果它一定有标签，可能是：餐饮，就算是 [0, 0, 0, 0, 1]）

现在，我们让计算机算一下，第一篇（A320的起飞）和这篇（炒方便面）之间的欧氏距离：

$$d = \sqrt{(1-0)^2 + (1-0)^2 + (0-0)^2 + (0-0)^2} = \sqrt{2} \approx 1.41$$

这里存在一个明显的逻辑漏洞。

第一篇（A320起飞）和第三篇（起降原理）的距离是 **1.41**。
第一篇（A320起飞）和第四篇（炒方便面）的距离竟然也是 **1.41**！

如果计算机死板地依靠欧氏距离，它会十分愚蠢地告诉你：“A320的起飞”和“炒方便面”的相关性，跟它和“起降原理”的相关性是一模一样的！如果你是研发总监，明天你的系统给搜索飞机的飞行员推荐了炒方便面，系统将变得不可用？

这显然是荒谬的。问题究竟出在哪里？

问题在于：**欧氏距离无法真正反映“相关性”。** 在欧氏距离的计算公式里，你因为“拥有一个不同的特征”所产生的距离，和你“缺失一个特征”所产生的距离，在数学上被等同对待了。这在处理高维稀疏特征时，是一场灾难。

### 4.3 换个角度看世界：点乘与夹角余弦

为了解决这个致命漏洞，我们要从初中几何稍微往前走半步，回忆一下高中数学里的另一个核心概念：**向量的点乘（内积）**。

什么是点乘？最直白的理解，点乘就是把两个向量在相同维度上的数字两两相乘，然后再全加起来。

我们用点乘来重新审视一下刚才的三篇文章：

* **A320起飞** `[1, 1, 0, 0]` 与 **起降原理** `[0, 1, 1, 0]` 的点乘：
$1\times0 + 1\times1 + 0\times1 + 0\times0 = 1$
（结果大于 0，说明它们在某个维度上有共鸣，产生了交集！）
* **A320起飞** `[1, 1, 0, 0]` 与 **炒方便面** `[0, 0, 0, 0]` 的点乘：
$1\times0 + 1\times0 + 0\times0 + 0\times0 = 0$
（结果是 0，说明它们无论怎么乘，都激不起任何水花，毫不相干！）

看！仅仅换了一种简单的数学运算，炒方便面就被系统完美地踢出了局。

在高中数学里，两个向量 $\mathbf{x}$ 和 $\mathbf{y}$ 的点乘，在几何上有一个优美的公式：

$$\mathbf{x} \cdot \mathbf{y} = \|\mathbf{x}\| \|\mathbf{y}\| \cos(\theta)$$

这里的 $\|\mathbf{x}\|$ 和 $\|\mathbf{y}\|$ 是两个向量的模（也就是长度），而 $\theta$ 是它们在多维空间中的夹角。

如果我们只想知道这两个向量的“方向”是不是一致的，我们其实只需要看那个夹角 $\theta$。把长度除过去，我们就得到了现代人工智能评估相似度最核心的公式——**余弦相似度 (Cosine Similarity)**：

$$\cos(\theta) = \frac{\mathbf{x} \cdot \mathbf{y}}{\|\mathbf{x}\| \|\mathbf{y}\|}$$

* 如果两篇文章方向完全一致，夹角 $\theta = 0^\circ$，$\cos(0^\circ) = 1$。这就是**绝对契合**。
* 如果两篇文章风马牛不相及（方向完全垂直），夹角 $\theta = 90^\circ$，$\cos(90^\circ) = 0$。

只要我们抛弃绝对的直线距离，转而去计算**夹角余弦**，“炒方便面”的闹剧就永远不会发生了。

### 4.4 终极技术：L2 归一化 (L2 Normalization)

讲到这里，有高中数学常识的各位可能会问出一个十分本质的问题：

**欧氏距离，夹角余弦，点乘。这三个东西，到底是什么关系？难道我们在写 AI 代码的时候，要根据不同的场景在它们之间切来切去吗？**

这不符合计算机科学中“大道至简”的美学。于是，AI 工程师们施展了一个巧妙的数学运算——**L2 归一化 (L2 Normalization)**。

既然各个向量的“长度”不一会干扰我们的计算，那我们在把向量存入数据库之前，做一个暴力的操作：**强行把所有向量的长度变成 1。**

在数学上，就是用向量里的每一个数字，除以它自己的模长。在几何上，这意味着把多维空间里所有长短不一的向量，全部拉伸或压缩，统一投射到一个**“单位超球面”**的表面上。

现在，接下来我们看看实际效果。

假设所有的向量都从原点出发，且它们的模长全都被强制变成了 1，即 $\|\mathbf{x}\| = 1$ 且 $\|\mathbf{y}\| = 1$。那么我们来看看最初的那三个概念会发生什么奇妙的化学反应：

**第一，关于点乘。**
根据刚才的公式：$\mathbf{x} \cdot \mathbf{y} = \|\mathbf{x}\| \|\mathbf{y}\| \cos(\theta)$
代入长度为 1：$\mathbf{x} \cdot \mathbf{y} = 1 \times 1 \times \cos(\theta) = \cos(\theta)$
结论：**在单位超球面上，两个向量的点乘，直接等于它们的夹角余弦！**

**第二，关于欧氏距离。**
我们来算一下这两个终点之间的直线距离的平方 $d^2 = \|\mathbf{x} - \mathbf{y}\|^2$。
大家还记得初中的完全平方公式吗？在向量世界里，它叫余弦定理展开：

$$\\|\mathbf{x} - \mathbf{y}\|^2 = \|\mathbf{x}\|^2 + \|\mathbf{y}\|^2 - 2(\mathbf{x} \cdot \mathbf{y})$$

把长度为 1 代进去：

$$d^2 = 1^2 + 1^2 - 2\cos(\theta) = 2 - 2\cos(\theta)$$

得出最终的完美公式：

$$d = \sqrt{2 - 2\cos(\theta)}$$

**它把直线的距离（$d$）和旋转的角度（$\cos(\theta)$），十分完美地绑定在了一起。**

当两篇文章越来越相似时，夹角越来越小，$\cos(\theta)$ 越来越接近 1。此时，公式里的 $2 - 2 \times 1 = 0$，欧氏距离 $d$ 也就无限趋近于 0。

殊途同归！在完成了 L2 归一化之后，无论你是算点乘、算余弦相似度、还是算欧氏距离，在数学本质上已经是**完全等价**的了！

那炒方便面的事情解决了吗？让我们用新武器重新验证一下。

还记得那个让欧氏距离出洋相的例子吗？"A320的起飞" `[1, 1, 0, 0]` 和 "炒方便面" `[0, 0, 0, 0]` 的欧氏距离是 1.41，跟"起降原理"一样。但现在，我们用点乘来审判它：

$$\mathbf{x} \cdot \mathbf{y} = 1 \times 0 + 1 \times 0 + 0 \times 0 + 0 \times 0 = 0$$

**点乘直接等于 0！** 两个特征向量在多维空间里完全垂直，夹角 $\theta = 90^\circ$，$\cos(90^\circ) = 0$。在我们这个极简的 4 维手工模型里，它们没有任何维度上的交集，判定为**完全不相关**——干净利落。

在我们手工打造的 4 维标签空间里，点乘为 0 是完全精确的。但当我们用真正的大模型来处理同样这两篇文章时，你会发现炒方便面和 A320 起飞的余弦相似度并不是绝对的 0。为什么？因为真实的大语言模型在处理文本时，会捕捉到标点符号、中文字符等通用语法结构，所以在 1024 维的空间里，几乎永远不会出现绝对的正交。

讲了这么多文本和博客，大家千万不要产生一个误区，以为只有文字才能变成向量。在现代人工智能的眼里，真正的哲学是：**万物皆可向量化。**

比如**图片**。 我们要用 AI 来识别发动机叶片的探伤照片。计算机看不懂"裂纹"，但我们可以提取这张图片矩阵的特征值（Eigenvalues），或者计算出图片的感知哈希（Perceptual Hash），把每一个比特位当成一个维度。瞬间，一张复杂的工业探伤照片，就变成了一个几百维的数字向量。

但作为一个航空公司，我们拥有比图片更激动人心的数据——**飞机的实时飞行数据（QAR）**。

假设一架正在进近降落的波音 737。它在空中的状态是由什么决定的？是空速（Airspeed）、地速（Ground speed）、无线电高度（Radio Altimeter）、气压高度（Barometric Altimeter）、俯仰角（Pitch）、迎角（AOA）、甚至是左右发动机的 N1 转速。

这些物理状态互相之间都有严密的空气动力学关联。如果我们提取飞机上的 500 个核心传感器数据，那么各位请发挥一下想象力：**这架波音 737 在这一秒钟的绝对飞行状态，在数学上，不就是刚才我们讲过的，一个 500 维空间里的一个特征向量吗？**

这架飞机在天空中每秒钟都在往前飞，它的各项参数都在变化。那么在这个 500 维的抽象宇宙里，这架飞机实际上是在运动的，它画出了一条连续的轨迹曲线！

为什么现代 AI 痴迷于把万事万物都向量化？因为一旦变成了向量，我们刚才讲的"算距离"的技术，就可以直接用来解决航空业最痛点的安全和合规问题！

以前，我们的安全部怎么抓**"不稳定进近"**或者**"事故征候（Incident）"**？我们需要资深的飞行专家写上百条死板的 IF-ELSE 规则："如果高度低于 1000 英尺，且下降率大于 1000，且空速大于 Vref+20……则报警"。这种规则极度僵化，往往抓不住复杂的、多重因素叠加的特情。

但在 AI 的高维向量空间里，事情变得无比简单优美。我们把过去一年里几十万个安全、平稳降落的航班数据扔进去，这些代表"安全状态"的成千上万个向量点，会在 500 维空间里自然地聚集在一起，形成一条粗壮的**"安全走廊"**。
