## 为什么很多科技公司都需要"双实体"？

::: incremental
- 软件公司天然面向**全球市场**，但中国企业在境外收款、转账受到严格外汇管制
- 核心知识产权（代码、品牌）放在国内，面临**更高的司法管辖风险**
- 国内企业所得税 **25%**，香港仅 **8.25%**，甚至可申请离岸豁免至 0%
- 国内公司向境外支付（服务器、工资）需要备案审核，香港可**自由多币种转账**
- 国际投资人（VC）普遍**只投海外主体**（开曼、香港），不投内资公司
:::

::: notes
在介绍我们的架构之前，我想先给大家做一个基础科普，解释为什么几乎所有有全球化野心的中国科技公司，都会在境外设立实体。

核心矛盾在于：互联网和软件业务是全球化的，但中国的公司架构是本地化的。一家纯粹的内地公司，想收美国用户的钱，需要走结汇；想给波兰员工发工资，需要备案；核心代码放在内地，一旦被查封，全球业务中断。

这就是为什么从字节跳动到小米，几乎所有有国际业务的公司，都会在香港或开曼设立集团总部。
:::

## 常见的三种"出海"架构

:::::::::::::: {.columns}
::: {.column width="33%"}
**VIE 架构**

🏗️ 阿里巴巴、京东、滴滴模式

- 境外 HoldCo 持有合同权益
- 国内 VIE 实体**无法分红**给国内股东
- 专为 IPO 设计，结构极复杂
- 国内股东利益**完全从属**于境外
:::
::: {.column width="33%"}
**WFOE 外商独资**

🏢 正式母子公司

- 境外公司 100% 持股内地子公司
- 结构清晰，合规度最高
- 注册门槛高，ODI 审批繁琐
- 适合已有 VC 融资的规模企业
:::
::: {.column width="33%"}
**影子跨国集团** ← 我们

🤝 深度关联的平行实体

- 两家独立公司通过合同协同
- **双方股东均可独立分红**
- 灵活、低成本、合规
- 适合早期高增长企业
:::
::::::::::::::

::: notes
出海架构大致分三种，各有适用场景。

第一种是 VIE——可变利益实体。这是滴滴、阿里巴巴、京东上市时用的结构。境外公司通过一系列合同"控制"内地公司，但内地公司的股东实际上只是名义持股人，拿不到真实分红。这种架构是专门为了在美股上市而设计的，极其复杂，且对内地股东极不友好。

第二种是 WFOE，也就是外商独资企业。境外公司直接通过 ODI 审批，100% 持股内地子公司。这是最规范的母子公司结构，但审批流程繁琐，注册资金要求高，适合已经拿到融资的成熟企业。

我们用的是第三种——我们自己摸索出来的"影子跨国集团"模式：两家独立的公司，通过法律合同深度绑定，像一家公司一样运作，但双方的股东都可以独立分红，彼此不从属。
:::

## VIE 是什么？为什么我们明确拒绝？

:::::::::::::: {.columns}
::: {.column width="55%"}
**VIE（可变利益实体）的本质**

::: incremental
- 境外壳公司通过"协议控制"内地公司
- 内地公司股东**名义上持股，实际上交出控制权**
- 内地公司的利润通过"服务费"等方式**强制流向境外**
- 内地股东：**有股份、无分红、无话语权**
:::
:::
::: {.column width="45%"}
**我们拒绝 VIE 的理由**

::: incremental
- 苏州股东将沦为**"名义股东"**
- 苏州公司变成无法分红的**皮包公司**
- 完全失去对苏州资产的实际控制
- 中国法院近年来对 VIE **合法性存疑**
:::
:::
::::::::::::::

::: notes
VIE 是一个很多人听过但不太了解的词，我用一句话解释它的本质：VIE 就是"借别人的壳，用合同把别人的公司变成自己的"。

具体操作是：你在境外设一个壳公司，然后让境内公司的实际控制人签一堆协议，把境内公司的投票权、分红权、资产处置权，通过合同全部转让给境外壳公司。

这意味着什么？意味着内地的股东，哪怕持有 30% 的股份，实际上一分钱分红都拿不到，一票否决权都没有——所有的权益都通过协议流到了境外。

这对我们苏州的股东是不可接受的。你们今天坐在这里，是真正的股东，不是名义上的挂名人。我们不走 VIE，就是为了保护你们的真实利益。
:::

对我们这个阶段的公司来说，香港是最优选择。主要有四个原因。

第一，资金自由。香港是自由港，没有外汇管制。我们的全球收入直接进香港账户，想付给谁就付给谁，不需要商务局批准。相比之下，内地公司每一笔境外付款都要审批。

第三，IP保护。香港沿用英国法律体系，知识产权保护在国际上被广泛认可，VC做尽职调查时看到IP在香港，会放心很多。

第四，风险隔离。如果内地出现任何不可预见的法律风险，香港实体的资产和业务不受影响，全球服务继续运行。

## 我们是什么？—— 影子跨国集团（Shadow MNC）

::: incremental
- **不是 VIE**：苏州股东有真实股权、真实分红、真实话语权

::: notes
总结一下：我们是什么？

我们既不是 VIE，也不是 MCN，也不是已经完成合并的外商独资企业。我们是一个"影子跨国集团"——两家在法律上完全独立的公司，通过一套精心设计的内部协议，实现了协同运作。

这套架构的精妙之处在于：它卡了一个合法的"系统 Bug"。同一套核心资产，国内的法律认可苏州有经营权，国际的投资人认可香港有所有权。我们在两套法律体系之间，找到了一个都能接受的交叉地带。

这是无数跨国公司的精髓——只是我们在更早的阶段，用更低的成本，手工构建了出来。

## 为什么不能反向操作？—— 让苏州收购香港

::: incremental
- **ODI 备案地狱**：苏州持有境外股权，须向商务部 / 发改委 / 外管局三重审批，极其繁琐
- **税务陷阱**：香港利润分红回苏州，需按国内企业所得税率（25%）补交差额
- **资产主权风险**：IP 在苏州 = 进入中国司法管辖，国内一旦出事，全球服务全面瘫痪
- **投资人不认**：国际 VC 投的是"香港/开曼控股结构"，不是"中国内资总部"
- **结论**：苏州主导、香港打工 ≠ 更简单，等于把全部风险集中在管控最严的那一端
:::

::: notes
有人可能会想：既然苏州是实际干活的，能不能反过来，让苏州做总部，让香港做苏州的子公司，帮苏州在海外收款？

这听起来直觉上很合理，但这条路在实操中是一个陷阱，有三个致命问题。

第一，ODI 备案。只要苏州公司持有境外股权，就必须向国内三个部委——商务局、发改委和外管局——分别备案，流程极其复杂，还要每年汇报，灵活性大幅下降。

第二，税务。香港子公司赚的钱，分红给苏州总部，要按中国企业所得税率补差额缴税。我们现在的架构是利润尽量留在香港，享受 8.25% 的低税率。反向操作等于主动放弃这个优势。

第三，最重要的：IP 放在苏州意味着放在中国司法管辖下。一旦苏州公司因为任何国内法律风险被查封，我们的代码、域名、品牌，全部失控。香港的壳里什么都没有，全球用户的服务直接中断。

所以，反向操作看似简单，实则是把全部鸡蛋放在风险最高的那个篮子里。
:::

## 签署核心协议：《战略合作框架协议》

:::::::::::::: {.columns}
